# react-native-essentials-settings

Cross-platform React Native library for accessing device and system settings — theme, font scale, locale, RTL, reduce motion, and more — through one unified, TypeScript-first API.

## Installation


```sh
npm install react-native-essentials-settings
```


## Usage


```js
import { multiply } from 'react-native-essentials-settings';

// ...

const result = multiply(3, 7);
```
